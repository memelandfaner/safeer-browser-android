# Safeer Mobile 1.0.28

**Room for every device in Safeer Link.**

- Hub: when this phone hosts Safeer Link, up to 16 devices can be connected at once (TV, tablet, phone, computer, Safeer Control, Safeer OS) — before, the seventh was refused.
- The shared Safeer Link page gained a "Files for the TV" section that only Safeer Control on a computer shows; nothing changes on the phone.

Slovensko: Središče: kadar ta telefon gosti Safeer Link, je lahko hkrati povezanih do 16 naprav (televizor, tablica, telefon, računalnik, Safeer Control, Safeer OS) – prej je bila sedma zavrnjena. Skupna stran Safeer Linka ima nov razdelek »Datoteke za televizor«, ki ga kaže samo Safeer Control na računalniku; na telefonu se nič ne spremeni.

# Safeer Mobile 1.0.29

**Signing in works again, and your internet provider no longer sees which sites you open.**

- **Sign-in with Google, Facebook and X works again.** The pop-up window that these services open is handled properly, so the sign-in finishes and returns to the page you were on.
- **Pop-up windows without side effects.** Blocking unwanted pop-ups no longer breaks the windows a website legitimately opens; the rule is now a single, tested one instead of a set of exceptions.
- **Encrypted DNS is on by default.** The browser asks Cloudflare (1.1.1.1) over DNS-over-HTTPS, so your internet provider can no longer read which sites you open. You can switch it off in settings. Safeer Link keeps working on your home network, because local addresses bypass it.
- **Themes in settings are no longer cut off**, so the whole list can be seen and chosen.
- **The home page follows the app language**, English by default.
- The project is public: an English README with the install steps, a contributing guide and a code of conduct.

Slovensko: **prijava z Google, Facebook in X spet deluje** — pojavno okno teh storitev se pravilno obdela, prijava se konča in vrne na stran, kjer si bil. **Pojavna okna brez stranskih učinkov:** blokiranje vsiljivih oken ne pokvari več oken, ki jih stran zares odpre. **Šifriran DNS je privzeto vklopljen** (Cloudflare 1.1.1.1, DNS-over-HTTPS): ponudnik interneta ne vidi več, katere strani odpiraš; v nastavitvah ga lahko izklopiš, Safeer Link pa deluje naprej, ker gredo domači naslovi mimo njega. **Teme v nastavitvah se ne odrežejo več**, **domača stran govori jezik aplikacije** (privzeto angleško), projekt pa je javen z angleškim README, navodili za sodelovanje in kodeksom vedenja.

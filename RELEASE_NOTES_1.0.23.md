# Safeer Browser for Android 1.0.23

**Nujni popravek: domača stran in nov zavihek sta se v 1.0.22 odprla kot prazen pregledovalnik PDF.**

V 1.0.22 je nova možnost »odpri PDF z naprave« zajela tudi Safeerjeve lastne strani (domača stran,
Safeer Link), ker so prav tako naslovi `file://`. Zdaj se kot dokument z naprave odprejo samo
datoteke `.pdf`; domača stran in nov zavihek delujeta kot prej. Posodobitev namestite čez 1.0.22.
